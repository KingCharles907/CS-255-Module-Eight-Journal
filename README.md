# CS 255 DriverPass Portfolio

## DriverPass Project

DriverPass was a project for a driving school. The client wanted a system where students could schedule driving lessons, take practice tests, do online training, and check their progress. Admins would also be able to manage users and appointments.

## What I Did Well

I think I did a good job understanding what the client wanted and putting those needs into the design. I also did well with the diagrams because they helped show how the system would work.

## What I Would Improve

I would improve some of my diagrams. I would make them a little cleaner and easier to understand.

## User Needs

I looked at what students and admins would need to do in the system. I added things like scheduling appointments, taking practice tests, and viewing progress.

It is important to think about the user because they are the ones who will be using the system.

## My Design Approach

I usually start by figuring out what the system needs to do. Then I break it into smaller parts and use requirements and diagrams to plan everything out.

In the future, I would keep using UML diagrams and requirements because they help make the system easier to understand before building it.
